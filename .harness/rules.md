# Repository Rules

- Inspect before editing and make the smallest reasonable change.
- Preserve uncommitted work; never commit, push, reset, or discard changes.
- Only configured verification commands are run automatically.
- When a pull request is to be opened (a feature branch is ready for review),
  always create it with the GitHub MCP `create_pull_request` tool against the
  repository — base + head branch and a PR-template body. Never answer with
  only a link or a description of the PR you would open; open it.
